# tmp

this repo could have absolutely anything in it - most of the time it will be a placeholder page, but it could contain totally random things that i happen to be making for people at a given time

--

Edit `src/App.jsx` to change the page contents and set image filenames. 
Image filenames are resolved from `public/portfolio-images`.

## Scripts

- `npm run dev` starts the local dev server.
- `npm run build` builds the app into `dist`.
- `npm run preview` previews the production build locally.
- `npm run deploy` builds and publishes `dist` to GitHub Pages with `gh-pages` branch.

The project is configured to deploy at:

https://jacksondam.github.io/tmp

When you have added all images and text content:

1. Edit package.json name attribute to be your GitHub username (e.g. jacksondam)
2. Edit package.json homepage to be your GitHub Pages domain (e.g. https://jacksondam.github.io)
3. Run `npm run deploy` and push the repo!
